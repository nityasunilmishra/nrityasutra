# NrityaSutra (React + Vite)
1. Install Node.js (v18+), open this folder in VS Code.
2. Terminal: `npm install` then `npm run dev`
3. Open the http://localhost:5173 link shown.
Login/Sign up: demo auth stored in the browser (localStorage). Swap for Supabase/Firebase for real users.
Deploy: push to GitHub, import on Vercel (vercel.json is included).
